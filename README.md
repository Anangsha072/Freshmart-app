# FreshMart

FreshMart is an **online grocery store application** that allows users to browse, search, and order fresh fruits and vegetables. The app is built using **Node.js**, **Express**, **MongoDB**, and **React (Vite)**, with **Cloudinary** for image storage and hosting.  

---

## Features

- Browse a list of fresh organic fruits and vegetables.
- Search for products by name or category.
- Add products to the cart.
- Admin panel to add, update, and delete products.
- Images are uploaded and served via Cloudinary.
- Environment variables are used for sensitive data like database URLs and API keys.

---

## Tech Stack

- **Frontend:** React with Vite  
- **Backend:** Node.js, Express  
- **Database:** MongoDB (Atlas)  
- **Image Hosting:** Cloudinary  
- **Deployment:** Vercel (Frontend), Render/Heroku/Node server (Backend)  

---
## Prerequisites

- Node.js (v16+ recommended)
- npm or yarn
- MongoDB Atlas account (or local MongoDB)
- Cloudinary account
